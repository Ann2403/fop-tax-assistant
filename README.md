# Податковий помічник ФОП 3 групи

AI-асистент для ФОП і бухгалтерів малого бізнесу:

1. **Відповідає на податкові питання** з посиланням на статтю Податкового кодексу або роз'яснення ДПС (ЗІР).
2. **Готує чернетку квартальної декларації** ФОП 3 групи (неплатник ПДВ) з банківської виписки.

Наскрізний проєкт курсу AI Engineering. Подання декларації залишається за людиною — система лише готує чернетку.

## Статус

| Блок | Що | Статус |
|---|---|---|
| 1. Основи LLM | Витяг транзакцій з виписки, порівняння платної й локальної моделі | 🟡 в роботі |
| 2. Дані та RAG | Пошук по ПКУ + ЗІР з цитатами, тести якості | ⚪ |
| 3. Агенти та MCP | Агент «підготуй декларацію», інструменти як MCP-сервер | ⚪ |
| 4. Продакшн | API, захист, моніторинг, вартість | ⚪ |

## Документи

## Запуск

Потрібен [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env   # додати ключі API
```

## Дані

Реальні банківські виписки в репозиторій не потрапляють (`data/` у `.gitignore`). Для тестів використовуються синтетичні виписки з `eval/fixtures/`.
